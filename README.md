# WeSpace — 공간공감 인터랙티브 앱 프로토타입

학교 프로젝트용으로 제작된 정적 웹앱(PWA) 프로토타입입니다. 별도 서버나 DB 없이 브라우저에서 실행됩니다.

## 실행
가장 간단한 방법: `index.html`을 브라우저로 엽니다.

PWA 설치/서비스워커까지 확인하려면 폴더에서 간단한 로컬 서버를 실행하세요.

```bash
python -m http.server 8000
```

그 다음 `http://localhost:8000`에 접속합니다.

## 구현된 주요 화면/기능
- 공간공감 공식 로고 기반 스플래시 및 앱 아이콘
- 홈 / 공간 등록 / 사진 업로드 / 치수 입력 / '치수를 모르겠어요'
- LiDAR·공간 스캔 UX 시뮬레이션
- 용도·분위기·색상·예산 기반 디자인 설정
- 키보드/화면 버튼으로 이동 가능한 간단한 3D 공간 시뮬레이터
- WeSpace Original 가구 추천 및 3D 공간 배치
- 자체 제작 가구 직접 등록(프로토타입 관리자 기능)
- 커뮤니티 피드 / 좋아요 / 댓글 / '공간 제안' 기능
- 전문가 목록 / 1:1 상담 채팅 UX
- 마이페이지

## 실제 출시 시 연결할 기술
- iOS: ARKit + RoomPlan/LiDAR
- Android: ARCore 및 기기별 Depth API
- 3D: Three.js / Unity / Unreal 또는 네이티브 3D 엔진
- 상품: 관리자 CMS + 제품 DB + GLB/GLTF 3D 모델
- 커뮤니티/상담: 인증, 데이터베이스, 실시간 메시징, 결제 시스템
- AI: 공간 세그멘테이션, 이미지 기반 리디자인, 3D 재구성 모델/API

현재 버전은 발표와 사용자 흐름 검증을 위한 프로토타입이므로 실제 LiDAR 센서, 결제, 서버 저장, AI 3D 생성은 시뮬레이션으로 처리됩니다.
